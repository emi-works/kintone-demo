# 問い合わせの自動登録・通知（Google Apps Script × kintone REST API）

## 困りごと

**「フォームやメールで来た問い合わせを、毎回kintoneに手で入力している」**

問い合わせを kintone で管理していても、入口はWebフォームやメールのまま、という会社は多くあります。届いた内容を誰かがコピーして kintone に貼り付けるので、

- 入力の手間がかかり、転記ミスも起きる
- 入力されるまで担当者が気づかず、返事が遅れる
- 忙しい日に入力が漏れ、問い合わせそのものを取りこぼす

といった問題が起きます。問い合わせへの返事の遅れは、そのまま商談の機会損失につながります。

## 解決

Google Apps Script（GAS）と kintone の REST API を組み合わせ、問い合わせの登録から通知までを自動化しました。

1. **フォームもメールも、自動で kintone に登録**
   Googleフォームの回答は送信された瞬間に、Gmail の問い合わせメールはラベルを付けておくだけで5分おきに、kintone へ登録されます。人が転記する作業はなくなります。

2. **優先度と担当者を自動で決めて、すぐに通知**
   種別（導入相談・見積依頼・不具合など）と本文の言葉（「至急」「エラー」など）から優先度を判定し、種別ごとに担当者を割り当てます。担当者にはメールで（設定すれば Chatwork にも）すぐに通知が届きます。

3. **一次回答期限で、返事の遅れを防ぐ**
   優先度に応じて一次回答期限（高：2時間、中：24時間、低：72時間）を自動で設定します。kintone の一覧では、期限を過ぎた問い合わせを赤、迫っているものを黄色で表示し、「未対応」「期限切れ」「今日の受付」の件数もひと目で分かります。

## 工夫した点

- **取りこぼしゼロを最優先に**
  kintone への登録に失敗したときは、フォームの回答内容をそのまま管理者にメールで送ります。メールは登録に成功したものだけに「登録済み」ラベルを付けるので、失敗したメールは次の実行で自動的にやり直されます。kintone が混み合っているときは、少し待って最大3回まで再試行します。

- **二重登録を防ぐ**
  フォームの回答ID・メールのIDを kintone に保存し、同じものは登録しません。kintone 側でも重複を禁止する設定にしています。フォーム送信とメール取り込みが同時に動いても重ならないよう、GAS のロック機能も使っています。

- **API トークンをコードに書かない**
  接続情報は GAS の「スクリプト プロパティ」に保存し、公開しているコードには含めていません。GAS 用のトークンは「レコード閲覧・追加」だけの最小権限にすることを推奨しています。

- **登録されたあとの「対応漏れ」も防ぐ**
  自動登録だけでなく、kintone 側で期限の色分け・件数表示・「対応を開始する」ボタンを用意しました。「完了」にするときは対応メモを必須にし、何をしたかの記録漏れも防ぎます。

- **運用で変えたいところは1か所に**
  優先度を上げる言葉・担当者の割り当て・回答期限は、GAS の先頭の設定だけで変えられます。運用が変わっても、お客様の担当者が自分で調整できます。

- **お客様の環境に合わせやすい構成**
  Googleフォームは GAS が自動で作るので、設定は数分で終わります。Chatwork は使っている会社だけ設定すればよく、なければメール通知だけで動きます。

## 使用技術

- Google Apps Script（フォームのトリガー、Gmail の取り込み、時間主導のトリガー、ロック、スクリプト プロパティ）
- kintone REST API（レコード登録・重複チェック）
- Chatwork API（任意の通知）
- kintone JavaScript API・CSS（期限の色分け、件数表示、入力チェック）
- Node.js（kintone アプリの構築・デモデータ登録のスクリプト）、clasp（GAS のコード管理）
