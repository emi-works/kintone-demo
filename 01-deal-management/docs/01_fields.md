# 案件・顧客管理アプリ フィールド一覧

アプリ名（例）：**案件管理**

> **大事なポイント**
> - 「必須（標準）」に ○ がある項目だけ、フィールド設定の「必須項目にする」にチェックを入れてください。
> - それ以外の項目は**チェックを入れないでください**。ステータスによって必須かどうかが変わるため、JavaScript 側でチェックします。
> - 日付フィールドは「レコード登録時の日付を初期値にする」の**チェックを外して**ください（空欄のまま保存されるのを防ぐチェックが効かなくなるため）。
> - フィールドコードは JavaScript から参照するので、**表の通り正確に**入力してください。

## 見出し（ラベル）

ラベルにフィールドコードを付けると、JavaScript から項目と同じように表示／非表示を切り替えられます。
ステータスによって出し分ける見出しには、次のフィールドコードを付けてください。

| 見出し（ラベル） | フィールドコード | 表示されるステータス |
|---|---|---|
| ◆基本情報 | （不要） | 常に表示 |
| ◆次回アクション | `lbl_next_action` | リード／提案中／見積提出 |
| ◆提案・見積 | `lbl_quote` | 提案中／見積提出／受注／失注 |
| ◆受注 | `lbl_won` | 受注 |
| ◆失注 | `lbl_lost` | 失注 |
| ◆その他 | （不要） | 常に表示 |

「◆受注・失注」を1つのラベルにしている場合は、「◆受注」と「◆失注」の2つに分けてください（受注のときに失注の見出しが出ないようにするため）。

```
◆基本情報
  案件名 / 顧客名
  顧客担当者 / 電話番号 / メールアドレス
  自社担当者 / ステータス / 確度 / 見込み金額
◆次回アクション（lbl_next_action）
  次回アクション期限 / 次回アクション内容
◆提案・見積（lbl_quote）
  提案日 / 見積金額 / 見積提出日
◆受注（lbl_won）
  受注日 / 受注金額
◆失注（lbl_lost）
  失注理由 / 失注理由の詳細
◆その他
  備考
```

## 一覧の設定

「期限が近い・過ぎた案件の色分け」は一覧に表示されているフィールドを使って行うため、一覧（表形式）に次のフィールドを**必ず含めて**ください。

- 案件名 / 顧客名 / 自社担当者 / **ステータス** / **次回アクション期限** / 次回アクション内容 / 見込み金額

さらに、最初に開く一覧として **「進行中の案件」** を用意しています（APIで作成済み）。

- 絞り込み：ステータスが リード／提案中／見積提出 のいずれか
- ソート：次回アクション期限（昇順）→ レコード番号（昇順）

kintone の昇順ソートでは期限が空のレコード（受注・失注）が先頭に来てしまうため、進行中だけに絞り込んで、期限切れの案件が一番上に並ぶようにしています。元の「一覧1」はすべての案件を見る一覧として残しています。
